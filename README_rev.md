# カード検索サイト 改修版 v7（2026-11-14）

スマホ利用が全体という前提で、検索とデザインを改修した版です。
元のファイルは上書きしていません。このフォルダの7ファイルを、リポジトリのルートにある同名ファイルと差し替えるだけで反映されます。`data/` と `images/` は変更不要です。

## 差し替えるファイル
- index.html / top.css（TOP）
- eternal_return.html / style.css（Eternal Return、ダークテーマ）
- blue_archive.html / blue_archive.css（ブルーアーカイブ、ライトテーマ）
- script.js（共通）

## v7での追加（2026-11-14）
- キーワード能力で絞り込みを追加。「絞り込み」パネル内のコストの下に、カードテキストの【】ラベルから自動生成したチップ（件数つき）を表示
- 抽出ルール：【アクティブ：メイン】は「アクティブ」に、【クレジット5】は「クレジット」にまとめる。防壁［1］や突破［コスト4以下］のような［］付き表記もキーワード名で拾う
- 複数選択した場合は、選んだキーワードをすべて持つカードだけを表示（AND）。URLは `?kw=アタッカー,エグジット` の形で保持

## v6での修正（2026-11-14）
- 並び順を ST → BT → SB の弾順に変更（同じ弾の中は番号順）。SBはBTの後ろに置いた

## v5での修正（2026-11-14）
- 「もっと見る」を廃止し、検索結果は最初から全件表示にした（画像は遅延読み込みのままなので表示は重くならない）
- 並び替えを両タイトルから廃止し、固定順にした（v6で ST→BT→SB 順に変更）。旧URLに `?sort=` が残っていても無視される

## v4での修正（2026-11-13）
- Eternal Return側で色アイコン（ドットと文字）が全部黒になる問題を修正。ERテーマの文字色上書きが色クラスより優先されていたのが原因で、色ごとの指定を優先し直した
- 表示切り替えから「大きく」を廃止し、グリッド／リストの2つにした。前の版で「大きく」を選んでいた端末では自動でグリッド表示になる
- リスト表示のカードテキストを省略なしの全文表示に変更（区切りの破線つき、タグは色付きのまま）

## v3での修正（2026-11-13）
- 色フィルタを折り返し表示に変更し、スマホでも黄色まで全色が見えるようにした（「複数選べます」は独立した行に移動）
- 「画像なし」枠が画像と一緒に出てしまうバグを修正（hidden属性がCSSに負けていた）。画像が2つ並んで見えたのはこれが原因
- リスト表示のとき、名前・番号の下にカードテキスト（効果タグ色付き、最大4行）を表示するようにした

## 改修内容
### 検索
- フリーワード検索を追加：名前・効果・番号・所属・フレーバーを横断検索
- ひらがな→カタカナ、全角→半角の表記ゆれを吸収（「わかも」でも「ワカモ」に当たる）
- スペース区切りで複数キーワードのAND検索
- コスト絞り込みチップ（0〜4、5+）
- レアリティ／収録弾（BT09、ST14など）フィルタをJSONから自動生成
- 検索条件をURLに残すので、条件つきリンクを共有できる。詳細は `#BT09-028` の直リンクで開ける
- 色フィルタは複数選択式（もう一度タップで解除、ALLで全解除）。URLでは `?color=red,blue` の形で保持
- 詳細モーダルはダブルクリックでも閉じる（前へ／次へボタンの連打では閉じない）
- 条件リセットボタン、0件のときの案内とリセット導線
- スマホでは詳細フィルタは「絞り込み」ボタンで開閉（適用中の条件数がバッジ表示）

### スマホ向けデザイン・操作
- 検索パネルが画面上部に張り付き、ヒーローはスマホで低くしてカードが早く見える
- カード全体をタップで詳細が開く（小さい虫眼鏡ボタンを廃止）。タップ領域は44px以上を確保
- 一覧に名前・レアリティ・番号・コスト／パワーを表示。画像が読み込めないときは番号で代替表示
- 表示切り替え（グリッド／大きく／リスト）を追加し、選択を端末に記憶
- 詳細モーダル：前後のカードへボタンと左右スワイプで移動、Esc・背景タップで閉じる、開いている間は背景スクロールを止める
- テーマCSSは変数で色を差し替える共通構成に統一（style.css / blue_archive.css）
- footerを body 内へ移動、TOPのブルアカ画像の alt 間違いを修正、meta description / theme-color を追加
- 効果タグにの色を追加
